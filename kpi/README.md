# KPI

This folder contains the Key Performance Indicators defined for the sorting line.

## Objectives

- Define measurable industrial KPIs
- Track performance during simulation runs
- Feed the final report with quantitative results

## Planned KPIs

- Availability rate
- Hourly throughput (parts per hour)
- Sorting accuracy (per lane)
- Mean time between failures (simulated)
- Mean time to recover (simulated)
- Cycle time per part

## Contents

- `kpi/definitions.md`: KPI definitions and formulas
- `kpi/results.md`: results from the simulation runs
- `kpi/data/`: raw data and measurements
