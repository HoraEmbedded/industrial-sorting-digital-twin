# Screenshots

Portfolio screenshots of the project. Only final, clean captures belong here.

## Layout

- `factory-io/`: scene views, operator panel, light curtain
- `tia-portal/`: commented ladder networks, tag tables, watch tables
- `electrical/`: schematic exports

Images used inside documents (diagrams, figures) go to `docs/images/` instead.

## Conventions

- PNG format and numbered file names, for example `01-scene-overview.png`
- Crop to the useful area, with no personal information or local paths visible
- Reference images with relative links
