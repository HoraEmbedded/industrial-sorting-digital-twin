# Scope

## In scope

- Design of an automated industrial sorting line
- PLC programming in TIA Portal for a Siemens S7-1200 or S7-1500
- Ladder and GRAPH programming for mode management and sorting logic
- Digital twin configuration in Factory I/O
- Co-simulation between PLCSIM and Factory I/O
- I/O mapping between the PLC program and the digital twin
- Electrical schematic of the PLC and its inputs and outputs
- KPI definition and measurement during simulation
- Demo video of the working system
- Final technical report

## Out of scope

- Real hardware procurement and physical commissioning
- Industrial network design beyond the simulation scope
- Safety certification or SIL rating
- Manufacturing of mechanical parts
- Deployment to a production environment

## Deliverables

- GitHub repository with clean history and documentation
- TIA Portal project exports
- Factory I/O scene
- Electrical schematic
- KPI definitions and results
- Demo video
- Final PDF report

## Assumptions

- The simulation runs on a single Windows workstation
- All software is available in the required versions
- The sorting line handles small and large boxes only
- Two sorting lanes are sufficient for the use case
