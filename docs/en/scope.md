# Scope

## In scope

- Design of an automated industrial sorting line by box height
- PLC programming in TIA Portal for a Siemens S7-1200 CPU 1214C DC/DC/DC
- Ladder programming for mode management and sorting logic
- Digital twin configuration in Factory I/O
- Co-simulation between S7-PLCSIM and Factory I/O
- I/O mapping between the PLC program and the digital twin
- Embedded performance indicators computed in the PLC (`FB_Kpi`)
- Electrical schematic of the PLC and its inputs and outputs
- KPI definition and measurement during simulation
- Demo video of the working system
- Final technical report

## Out of scope

- Real hardware procurement and physical commissioning
- Industrial network design beyond the simulation scope
- Safety certification or SIL rating
- Manufacturing of mechanical parts
- Deployment to a production environment
- Migration to another controller family (S7-1500, S7-300, etc.)

## Deliverables

- GitHub repository with clean history and documentation
- TIA Portal project exports
- Factory I/O scene
- Electrical schematic (five sheets: two in QElectroTech, three generated by Python)
- KPI definitions and measured results
- Demo video
- Final PDF report

## Assumptions

- The simulation runs on a single Windows workstation
- All software is available in the required versions (TIA Portal V18, S7-PLCSIM V18, Factory I/O 2.5.10)
- The sorting line handles low and high boxes only
- Two exit lanes are sufficient for the use case
- The controller is a Siemens S7-1200 CPU 1214C DC/DC/DC, simulated with S7-PLCSIM
